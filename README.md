# Event Management Website

## 📖 Overview

EventSphere is a responsive event management website built using HTML, CSS, and JavaScript. It helps users explore upcoming events, view schedules, check ticket prices, and learn about guest chefs and special attractions.

## ✨ Features

- Event Listings
- Event Timetable & Schedule
- Ticket Pricing Information
- Guest Chef Profiles
- Event Details & Highlights
- Responsive Design
- Interactive User Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Anjan2082/schoolmang.git
```

2. Open the project folder.

3. Run `index.html` in any modern web browser.
